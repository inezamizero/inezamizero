# Goals

## The Core Problem I Am Solving
Rwandans in the diaspora cannot easily find Catholic prayers in Kinyarwanda online.
I had this problem myself when I moved to the US — I was lucky to have physical books.
Most people don't have those books anymore.

## Short-Term Goal (This Project)
Build and deploy Siyoni — a free, beautiful, culturally grounded Catholic prayer website in Kinyarwanda.
Name meaning: Zion — the holy mountain, the place the diaspora longs for.

## Medium-Term Goal (6–12 months)
- Add Swahili content (East African diaspora)
- Add prayer reminders (PWA push notifications)
- Add a book store for religious books

## Long-Term Goal (2–3 years)
- Native mobile app — like Hallow but for African Catholic diaspora
- Multiple African languages
- Partnerships with African dioceses and Catholic publishers

## Revenue Path
1. Ko-fi donations — ko-fi.com/siyoni (launch day)
2. Google AdSense (when traffic grows)
3. Religious book sales (v2)
4. Premium features — offline access, PDF downloads (v3)
